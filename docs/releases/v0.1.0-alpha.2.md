IPA Decrypt Lab v0.1.0-alpha.2，更新预览版。

修复 Apple 新原生认证与 Store AMD/SP 设备注册，恢复真实应用下载及完整解密。保留系统 bag 请求上下文和 `X-Apple-Store-Front` 商店区域字段；账号令牌与设备证明仍绑定到指定 Apple 接口，配置请求清除账号认证字段。

正式运行包已在 X（App ID `333903271`）完成登录、下载、解密、账号元数据清理及加密导出：32 个加密切片、86,704 页通过完整性验证。明文 IPA 为 271,261,630 字节，未公开发布。[真实验证记录](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42439908718/attempts/2)。安装运行和本次新的 Telegram 文件发送未计入验证。

包含 Linux amd64 VPS 控制器、macOS 26 Intel 与 macOS 15 Intel 运行包。另附 `SHA256SUMS`、`BUILDINFO.json`、发布说明和许可证。两个 macOS 平台的原生构建执行 440 项 Python 测试（各跳过 2 项）与 21 项 Swift 测试，并完成运行包独立启动检查；VPS 包另经 Ubuntu 与 Debian 13 验证。

用途与配置见[成品包说明](https://github.com/zwthys-cyber/ipa-decrypt-lab/blob/v0.1.0-alpha.2/docs/RELEASES.md)。包内不含 Apple 账号、授权模型、交付私钥、Telegram 凭据或应用 IPA。当前仍仅开放管理员私聊、美区免费应用，IPA 上限 2000 MB；不承诺多用户、收费或安装运行兼容性。

本次替换旧版公开 Release，保留源码标签及历史记录。发布成品不会自动部署或重启 VPS；在线工作流仍按精确源码指纹获取 Actions 运行包。项目及依赖的现有许可证保持不变。
