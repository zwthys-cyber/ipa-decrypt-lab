# v0.1.0-alpha.3 — 进度与导出加速版

本版将已验证的进度卡和导出加速打包到公开预览成品，仍供配置的管理员私聊使用。

- 进度卡显示流程步骤比例、原生真实下载字节百分比、总耗时和阶段耗时；约 5 秒刷新计时，重启后沿用原任务时间和卡片。
- 总体 100% 仍要求 Telegram 文件发送确认。没有可靠字节计数的阶段不伪造剩余时间或上传百分比。
- 通过经过摘要、任务、运行和源码绑定的小型 Actions 快照读取进度，无需扩大 VPS token 的 Checks 权限。
- ZIP 账号清理直接复制保留成员的压缩数据，保留完整页面、清单、CRC 和摘要校验；X 后台单次对比从 128 秒降到 103 秒，包体约增加 3%。
- 官方 Actions 固定到 Node.js 24 版本，消除旧依赖的弃用警告。

双平台生产运行 42445031389、合成基准 42445037747、真实 X 导出 42445425200 已通过。两个 Intel 平台各运行 451 项 Python 测试（各跳过 2 项）、2 项 Node 测试、21 项 Swift 测试和 Go/独立启动检查。运行来源及摘要以附件 BUILDINFO.json、SHA256SUMS 为准。

附件包括 Linux amd64 VPS 服务端、macOS 26/15 Intel 运行包、校验和、构建来源、说明和许可证，不含账号、模型、服务凭据或应用 IPA。配置和安装见 [成品说明](../RELEASES.md)。

这是预览版，当前仅管理员私聊、美区免费应用，IPA 最大 2000 MB。没有多用户、收费或重签名后安装运行验证。发布不会自动部署或重启服务器；既有 alpha.2 附件和标签保持不变。
