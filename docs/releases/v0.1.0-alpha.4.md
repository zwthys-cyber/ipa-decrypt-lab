# v0.1.0-alpha.4 — 多用户白名单版

本版将管理员私聊入口扩展为管理员控制的多用户白名单，保留 alpha.3 的进度、真实下载计数、完整计时、Node.js 24 Actions 和导出加速。

- 固定管理员使用 `/allow 用户ID [每日额度]`、`/deny 用户ID`、`/users` 管理白名单。默认只有管理员有权限，没有公开注册或收费入口。
- 普通用户默认每日 3 次，服务总额度仍默认每日 20 次；共享串行准入和版本查询全局额度，已有缓存仍可查看。
- 任务、取回文件、列表、回调、进度和恢复记录按用户隔离。知道他人任务编号不能取回文件，所有发送绑定到记录所属私聊。
- 撤权、取消与全局终止占位持久化，重启不会自动交付已取消、撤权或发送不确定的任务。
- 保留管理员旧 hash 作用域与全局更新游标，六项服务凭据无需重配；仍只运行一个常驻轮询进程。线上不添加合成用户或发送测试 IPA。

服务器构建运行完整 Ubuntu/Debian 13 回归、Go、Node 和 systemd 检查；原生包分别验证 macOS 26/15 Intel。具体生产提交、运行编号、包来源和 SHA-256 以附件 BUILDINFO.json、SHA256SUMS 为准。新增 15 项真实临时 SQLite 的合成多用户测试；它们不能替代第二个真实用户的私聊交付证据。

附件仅含项目运行组件、说明、校验和及许可证，不含账号、模型、Telegram 凭据、交付私钥、用户授权名单或应用 IPA。美区免费应用和 2000 MB 限制不变，没有重签名安装运行验证。

使用步骤见[多用户说明](../MULTI-USER.md)，安装和回滚见 [VPS 说明](../VPS-DEPLOYMENT.md)，成品选择见[发布说明](../RELEASES.md)。alpha.2/alpha.3 和源码标签保持不变；发布和部署是独立操作。
