# v0.1.0-alpha.5：TestFlight 与链接地区识别

2026-11-09 按用户要求更新本预览版附件：新增主人私聊的 TF 邀请自动任务、持久会话恢复、一次性接受保护、严格明文校验和私聊交付。新 TF 文件带 `Beta` 标识，例如 `CapyPlayer_Beta_1.1.7.ipa`，App Store 命名不变。

[CapyPlayer 实际任务](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42714371079) 完成46个加密镜像/17,724页验证，用户提供的 Telegram 截图确认收到文件；该任务没有新接受邀请或电脑授权。[Beta 命名部署](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42714903713) 及真实无发送导出门禁通过。普通 TF 任务不密码重登、不新增电脑授权；会话失效、额外协议、限流或模型不兼容时停止。

发送 `apps.apple.com/cn/...` 链接即可用独立中国区账号下载最新版；其他地区链接和纯数字 App ID 保持原外区账号。进度卡显示下载地区，任务重启恢复、取消和文件取回始终绑定原账号。国区失败不会切换外区。

中国区先支持免费最新版，外区历史版本和白名单、多用户隔离、统一额度、真实下载计数与完整计时均保留。普通国区任务复用保存模型，只进行非交互会话刷新；若需要验证码则提示管理员维护，不占用新的电脑授权。

国区模型已通过 LocalSend 的 31 个加密切片、11,744 页验证；在新 Intel 运行器用另一款应用完成 6 个切片、164 页的保存模型复用和状态重放。链接识别、账号隔离与 SQLite 恢复回归通过。最终导出、构建及部署记录见 [项目状态](../PROJECT-STATUS.md)。

发布附件为 Linux amd64 控制器和默认 macOS 26/15 Intel 运行包，以及摘要、来源与许可证。CN 原生客户端及 TF SDK 由各自独立 GitHub 工作流构建，按源码指纹/ABI加载，不包含在默认客户端包中。所有 Apple 账号、会话、模型、状态、Telegram token、交付私钥和应用 IPA 均不随包分发。

这是预览版；中国区历史版本、收费、重签名安装和实际运行兼容性仍不在已验证范围。具体配置见 [中国区说明](../CHINA-ACCOUNT.md) 和 [发布文档](../RELEASES.md)。

[国区真实导出](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42565938868) 已通过 6 切片、164 页及清理/加密回执核验；[线上部署](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42566050391) 返回服务 ready。原始发布标签保留在 `48ad5b75eb61a6cc5f01ffb539f06a33055adc9a`；本次附件已重新选择当前源码成品，准确来源见 `BUILDINFO.json` 与包内 `SOURCE_COMMIT`。此次重新打包不部署或重启 VPS，也不发送应用文件。
