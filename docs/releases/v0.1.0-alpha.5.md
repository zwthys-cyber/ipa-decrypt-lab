# v0.1.0-alpha.5：按链接选择国区或外区账号

发送 `apps.apple.com/cn/...` 链接即可用独立中国区账号下载最新版；其他地区链接和纯数字 App ID 保持原外区账号。进度卡显示下载地区，任务重启恢复、取消和文件取回始终绑定原账号。国区失败不会切换外区。

中国区先支持免费最新版，外区历史版本和白名单、多用户隔离、统一额度、真实下载计数与完整计时均保留。普通国区任务复用保存模型，只进行非交互会话刷新；若需要验证码则提示管理员维护，不占用新的电脑授权。

国区模型已通过 LocalSend 的 31 个加密切片、11,744 页验证；在新 Intel 运行器用另一款应用完成 6 个切片、164 页的保存模型复用和状态重放。链接识别、账号隔离与 SQLite 恢复回归通过。最终导出、构建及部署记录见 [项目状态](../PROJECT-STATUS.md)。

发布附件为 Linux amd64 控制器和默认 macOS 26/15 Intel 运行包，以及摘要、来源与许可证。CN 原生客户端由独立 GitHub 工作流构建并按指纹加载，不包含在默认客户端包中。所有 Apple 账号、会话、模型、状态、Telegram token、交付私钥和应用 IPA 均不随包分发。

这是预览版；中国区历史版本、收费、重签名安装和实际运行兼容性仍不在已验证范围。具体配置见 [中国区说明](../CHINA-ACCOUNT.md) 和 [发布文档](../RELEASES.md)。

[国区真实导出](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42565938868) 已通过 6 切片、164 页及清理/加密回执核验；[线上部署](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42566050391) 返回服务 ready。运行源码和发布标签均为 `48ad5b75eb61a6cc5f01ffb539f06a33055adc9a`，后续仅更新说明；本轮未额外发送 Telegram 测试文件。
