# 原生下载流程修正

首次独立 Swift 试验已经登录成功（无需验证码），随后下载失败：
https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/41727238337

因此可以确认当前凭据在这条客户端链路中能完成登录，不应继续把所有问题归因于双重认证。

源码检查发现下载命令会在刚登录成功后无条件重新认证，并在目标应用缺授权时直接抛错。修正为复用刚建立的会话；遇明确 licenseRequired 时，只对当地商店已确认 price==0 的免费应用获取许可并重试一次。外层仍检查官方 US 元数据免费；两处免费检查同时生效。不自动同意账号安全升级或新的条款。

新增下载失败分类，所有上游原始输出仍在内存内处理，不转发账号或授权信息。此修正尚待真实下载结果验证。
