# 多用户白名单

本版仅面向管理员授权的私聊用户，不是公开注册或收费服务。原有 `TELEGRAM_OWNER_ID` 是唯一管理员；部署后默认没有其他用户。无需增加 GitHub Secrets。

## 如何授权

1. 让对方在 @ipazake_bot 私聊发送 `/start` 或 `/id`。未授权时只显示他自己的数字 ID，不创建下载任务。
2. 对方把数字 ID 发给管理员。管理员在自己的机器人私聊发送 `/allow 用户ID 3`，其中“用户ID”替换成对方的实际数字。
3. 对方再次使用机器人，即可发送应用链接或使用 `/versions`、`/version`。不会在授权时主动向对方发送测试文件或消息。

| 管理员命令 | 行为 |
| --- | --- |
| `/allow 用户ID` | 授权，默认每 UTC 日 3 次 |
| `/allow 用户ID 每日额度` | 授权或修改额度，范围为 1 到服务总额度 |
| `/deny 用户ID` | 移除授权，停止待处理任务的自动交付并请求取消后台工作 |
| `/users` | 查看白名单与每人额度 |

普通用户不能管理授权；管理员身份不能通过这些命令转让或移除。最多 50 名已授权普通用户。需要对方先主动开始私聊，用户 ID 列表只保存在服务器私有数据库中。

## 额度和同时使用

普通用户默认每日 3 次，管理员可调整；管理员仍受服务总额度限制。`IPAZAKE_DAILY_TASK_LIMIT` 继续控制全服务的 UTC 日提交总量，默认 20 次，包含失败与取消的提交。修改或撤销再授权不会重置当天使用量。

一次仅接纳一个用户的下载或实时版本查询；其他用户会收到忙碌提示，可稍后提交，也可以查看自己的缓存列表和既有文件。没有引入后台无限排队。原有同一用户缓存后台刷新和下载的串行规则保留。每人及全服务的远程版本查询都限制为滚动 24 小时 20 次，缓存浏览不计入。

## 数据归属

每个人的任务、文件取回、列表、按钮、进度卡、每日计数和恢复记录分别隔离。`/status`、`/cancel` 和 `/get` 只作用于自己；管理员用普通文件取回入口也不能仅凭其他用户任务编号取文件。群聊、伪造私聊绑定和未授权回调不提交任务。

所有用户共用受信任服务器和固定交付加密身份，隔离由应用权限与私有恢复记录执行。Apple 账号和模型仍只在 GitHub，普通用户接触不到凭据。公开产物仍仅保留一天的交付密文和固定数字快照，不写入 Telegram 用户 ID、聊天内容或授权名单。

## 撤权、取消和重启

撤权将 ACL、待处理任务的取消状态、版本查询关闭和需要确认的后台工作写入同一事务。用户取消也持久记录取消意图；已取消、已完成或发送结果不明的任务不自动重新发送。已确认送达的文件不会因后续撤权而撤回。

后台取消可能延迟。服务只在确认工作流已结束后释放占位；平台暂未返回或查不到任务时保持保守，不盲目重提或释放。发生长时间未确认时应核对 GitHub 运行和恢复记录，不能通过清空数据库绕过保护。

一个进程使用一个全局更新游标，防止相同 Telegram 更新在用户之间重放。任务数据沿用各用户原有 hash 作用域，原管理员数据无需迁移。整库备份覆盖名单和所有任务；回滚见 [VPS 部署](VPS-DEPLOYMENT.md)，发送不确定行为见[恢复说明](SESSION-RECOVERY.md)。

## 验证边界

新增测试使用真实临时 SQLite 和合成 Telegram/GitHub 客户端，验证跨用户任务号、接收方绑定、回调、额度、撤权、取消、重启和更新去重。线上不会自动加入测试用户。真实第二个用户的私聊提交和交付须由管理员授权实际用户后再单独记录；合成测试不代表进行了真实多用户文件发送。

本版已经[部署并通过健康检查](https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42543133206)，[公开 alpha.4](https://github.com/zwthys-cyber/ipa-decrypt-lab/releases/tag/v0.1.0-alpha.4) 提供匹配成品。Ubuntu/Debian 13 各完成 466 项 Python 测试（各跳过 1 项）；两个 macOS Intel 平台各完成 466 项 Python（各跳过 2 项）、2 项 Node、21 项 Swift 和 Go/独立启动检查。[完整证据](PROJECT-STATUS.md)。线上没有加入合成测试身份，其他真实用户须由管理员自行授权。

## 中国区与外区共用额度

alpha.5 按 App Store 链接选择下载账号，`/cn/` 为中国区，其余链接或纯数字仍为原外区账号。选择地区不创建新的用户额度，不绕过串行准入；任务恢复、取回和撤权沿用原私有作用域。中国区支持免费最新版及可获取的历史版本，下载用户无需填写 Apple 凭据或验证码。

## TF 权限边界（2026-11-09）

TF 邀请目前仅向配置的主人开放，`/allow` 不会授予普通白名单用户 TF 权限；其他用户仍使用 App Store 路线。TF 与 App Store 沿用现有全局准入和主人任务记录，`/status`、`/cancel`、`/get` 仍绑定原用户与请求。TF 不支持 App Store 历史版本命令。见 [TF 使用说明](TESTFLIGHT.md)。
