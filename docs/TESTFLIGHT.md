# TestFlight

TestFlight 入口面向配置主人的私聊，使用独立的保存会话获取可用 iOS 测试构建。当前平台已接入处理流程，新的真实请求仍待完整验收。

## 提交方式

直接发送完整邀请链接：

```text
https://testflight.apple.com/join/<邀请码>
```

TestFlight 不使用 App Store 历史版本参数。测试包文件名保留 Beta 标识。

## 处理规则

| 情况 | 行为 |
| --- | --- |
| 已有成员资格 | 复用资格，不重复接受邀请 |
| 新邀请且具备条件 | 先持久记录意图，再执行一次有界接受 |
| 接受或提交结果不明 | 保留意图，不自动重新提交 |
| 会话拒绝、限流、额外协议或模型不兼容 | 明确停止，进入对应维护流程 |

普通任务使用原独立会话，不自动密码登录、重建身份或新增电脑授权。无法获得匹配构建或通过完整明文校验时，不生成交付结果。

## 状态与恢复

历史接受确认、稳定 HMAC 和私有回传记录需要持续保留。会话过期不会清除接受意图，未知结果也不会因时间经过而自动变成可重试。

当前验证范围见[项目状态](PROJECT-STATUS.md)，接受历史和早期真实取包记录见[TestFlight 档案](archive/2026-11-27/TESTFLIGHT.md)。取消及恢复规则见[任务恢复](SESSION-RECOVERY.md)。
