# 费用与额度

项目按个人使用、按需处理的方式运行。控制面负责接收请求和保留状态，工作机在任务到来后启动。

## 费用策略

- 不自动开通付费计划、升级订阅或启用按量超额。
- 新平台或套餐需要先核对账号配置、额度及停止条件。
- 免费额度和供应商条款可能变化，用量与账单需要由各平台配置核实。

这些约束不构成供应商长期免费或账号账单上限的证明。历史平台比较按原调查日期保留，见[费用评估档案](archive/2026-11-27/ZERO-COST.md)。

## 项目内额度

| 项目 | 当前规则 |
| --- | --- |
| 下载提交 | 配置的管理账号免每日业务次数限制 |
| 任务记录 | 成功、失败和取消继续记录，不以清空历史获得豁免 |
| 等待队列 | 最多 30 条，实际工作串行 |
| 目录查询 | 管理账号免每日业务次数限制，保留短时频率保护 |
| App Store IPA | 最大 2,000,000,000 字节 |
| 文件领取 | 注册后 24 小时的领取窗口 |

项目内额度用于控制请求，不替代平台账单设置。维护时同时检查 CircleCI、Cloudflare 和 Google Drive 的实际用量。

架构见[组件说明](MANAGED-RUNTIME.md)，配置流程见[维护手册](OPERATIONS.md)。
